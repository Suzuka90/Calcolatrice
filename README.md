# PHP-Simple-Calculator 🧮

**Calcolatrice web base PHP. Form HTML + logica server-side.**

[![PHP](https://img.shields.io/badge/PHP-8.2+-pink)](https://php.net)
<br>

## 📖 Descrizione
Calcolatrice **pura PHP** senza JavaScript.
- **Input:** Form HTML (`$_POST`)
- **Logica:** PHP `switch()` operazioni
- **Output:** Risultato matematico preciso
- **Server:** XAMPP/Apache
  <br>

**Obiettivo CV:** Fondamenti PHP form handling.
<br>

## 🛠 Tech
- PHP 8+ (`$_POST`, `switch`, `filter_input`)
- HTML form
- Operazioni: +, -, *, /
  <br>

## 🚀 Setup XAMPP
```bash
1. XAMPP Apache START
2. htdocs/calculator/index.php
3. http://localhost/calculator/
```
